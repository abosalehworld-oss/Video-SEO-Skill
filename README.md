# 🎬 مهاره سيو الفيديو — Video SEO Skill

> مهارة AI شاملة لتحسين محركات البحث لمحتوى الفيديو عبر جميع المنصات

## 📋 ما هي هذه المهارة؟

مهارة AI متكاملة (Skill File) مصممة لتعمل مع نماذج الذكاء الاصطناعي (Gemini, ChatGPT, Claude) لتحسين SEO لمحتوى الفيديو عبر جميع المنصات الرئيسية.

## 🔥 المميزات الرئيسية

- **Rule 0 — بروتوكول البحث الحي:** يبحث الـ AI تلقائياً عن أحدث تحديثات الخوارزميات للسنة الحالية قبل تقديم أي نصيحة
- **6 Phases كاملة:** من البحث → التحسين → النشر → التحليل
- **6 بوابات صارمة (Checkpoints):** تمنع التخطي أو الاختصار
- **مكافحة الهلوسة:** نظام إثبات لكل كلمة مفتاحية مع جدول Keyword Usage Report
- **GEO/AEO Layer:** تحسين ظهور الفيديو في محركات AI (ChatGPT, Gemini, Perplexity, AI Overviews)
- **YMYL E-E-A-T:** طبقة ثقة وخبرة لمحتوى الصحة والمال والقانون
- **Anti-Laziness Protocol:** يمنع الـ AI من الاختصار
- **Required Strings Check:** فحص ميكانيكي للتأكد من اكتمال كل deliverable
- **Uncertainty Labels:** 5 مستويات وضوح لكل معلومة (📡/⚙️/📐/💡/⚠️)
- **Quick Reference Card:** بطاقة مرجع سريعة بالمقاسات والمعايير والصيغ
